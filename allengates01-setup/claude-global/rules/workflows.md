# How I like to work

- Start every project session by reading that project's `CLAUDE.md` and
  `MANIFEST.md` entry before doing anything else.
- When you finish a piece of work, update the project's line in
  `MANIFEST.md` — one line, current status.
- Finished deliverables that belong in the Brain Hub (Google Drive) go in
  `~/claude/brain-hub-sync/<project>/` and get a `MANIFEST.md` line. That
  folder mirrors to Drive on a timer — don't rely on it syncing instantly.
